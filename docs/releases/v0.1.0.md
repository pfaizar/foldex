The first public preview of Foldex, a native Windows file explorer built in Rust.

- Browse in tabs and split panes, with filename search and configurable views.
- Open the keyboard launcher with Ctrl+Alt+Space.
- Use native Windows file operations, clipboard, context menus, and Recycle Bin.
- Customize dark/light themes, shortcuts, sidebar, and workspace settings.

Download **Foldex-0.1.0-windows-x64-portable.zip**, extract the entire folder into
a writable location, and run **Foldex.exe**. GitHub's automatically generated
“Source code” downloads contain the source, not a ready-to-run application.

Requires Windows x64, a compatible DirectX 12 graphics adapter/driver, and the
[Microsoft Visual C++ x64 Redistributable](https://aka.ms/vc14/vc_redist.x64.exe).
The executable is unsigned, so Windows may show an unknown-publisher or SmartScreen
prompt. Desktop hardware coverage is limited for this preview.

The ZIP includes AGPL-3.0-only licensing and third-party notices. The corresponding
source is available at this release's tag and through GitHub's source downloads.

For updates, exit Foldex from its tray menu before replacing program files, and
preserve your session, theme, and named themes. Report problems through
[GitHub Issues](https://github.com/pfaizar/foldex/issues), including your Windows
version, graphics adapter, and reproduction steps.

If you enable **Default File Explorer**, turn it off in Options before moving or
deleting the portable folder, so Windows registrations are restored.
