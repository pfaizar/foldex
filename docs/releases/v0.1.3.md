Foldex 0.1.3 improves file dragging, Windows progress feedback and shortcut recording.

- Drag files and folders onto folder rows, split panes, breadcrumbs and sidebar folders, or transfer them to and from Explorer. Dragging an existing selection preserves all selected items; dragging empty space keeps rectangle selection.
- See a translucent drag preview with a shadow, stacked items and a selection count. Native Move to, Copy to and Create link in labels name the destination, and valid destinations are highlighted.
- Quick copy, move, rename and delete operations no longer flash a completed progress window. Longer managed operations show native progress after one second; Windows still handles cancellation, conflicts, elevation and errors.
- Record shortcuts before Windows menus or ordinary UI navigation consume their keys. Held modifiers appear immediately, Win/Alt combinations remain in the recorder, and Escape, focus loss or closing the dialog ends capture safely.
- Preserve both sides of modifiers, normalize shifted punctuation and prevent partial bindings after input overflow.

GitHub's **Source code (zip)** and **Source code (tar.gz)** downloads contain the corresponding source, not the Windows application.

Requires Windows 10 x64 (1809+) and compatible DirectX 12 graphics. The Visual C++ runtime is included. Builds are unsigned, so Windows may show an unknown-publisher prompt.

Update an installed copy through **Options → Application Updates**, or exit Foldex and run the new installer. Your saved settings and themes are preserved. Portable copies retain their existing storage behavior.
