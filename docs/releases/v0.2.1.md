Foldex 0.2.1 fixes a small color gap in the titlebar above the Inspector.

- The titlebar now paints one continuous band across the window, including
  the space above the Inspector panel.

**Download**

- **Foldex-0.2.1-windows-x64-setup.exe** — the Windows installer.
- **Foldex-0.2.1-windows-x64-portable.zip** — extract the whole ZIP and run
  Foldex.exe.

GitHub's **Source code (zip)** and **Source code (tar.gz)** downloads contain
the corresponding source, not the Windows application.

Requires Windows 10 x64 (1809+) and compatible DirectX 12 graphics. The Visual
C++ runtime is included. Builds are unsigned, so Windows may show an
unknown-publisher prompt.

Update an installed copy through **Options → Application Updates**, or exit
Foldex and run the new installer. Your saved settings and themes are preserved.
Portable copies retain their existing storage behavior.
