Foldex 0.1.1 adds a Windows installer and in-app application updates.

- Install for your Windows account with a custom folder, optional desktop shortcut and optional PATH entry.
- Open **Options → Application Updates** to check for new versions, download them, and choose **Install and restart**.
- Installed settings and themes live in your Windows user profile and survive updates, repairs and uninstall.
- Portable copies keep their existing storage behavior and can check for new releases.

**Download**

- **Foldex-0.1.1-windows-x64-setup.exe** — the Windows installer.
- **Foldex-0.1.1-windows-x64-portable.zip** — extract the whole ZIP and run Foldex.exe.

GitHub's **Source code (zip)** and **Source code (tar.gz)** downloads contain the corresponding source, not the Windows application.

Requires Windows 10 x64 (1809+) and compatible DirectX 12 graphics. The Visual C++ runtime is included in the builds. Builds are unsigned, so Windows may show an unknown-publisher prompt.

Exit any running Foldex windows and its tray instance before installing. Choose a separate installation folder from an existing portable copy. To migrate preferences, exit both copies and copy your portable theme.toml, foldex-session.json and themes folder into %LOCALAPPDATA%\Foldex\data.

Uninstall through Windows Settings → Apps. Your personal settings are preserved.
