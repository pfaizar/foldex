Foldex 0.2.0 adds a Windows startup option and keeps file views responsive as
you scroll and switch tabs.

- Start Foldex quietly in the system tray when you sign in. Enable it in
  Options, or choose it during a fresh install.
- Drag a selected item from anywhere on its row. Empty space and unselected
  rows still start a selection rectangle.
- Folder sizes and sort results stay ready as you scroll and switch tabs,
  avoiding repeated background work.
- Search notices when a monitored folder is deleted or replaced, even if
  Windows sends no change event.

**Download**

- **Foldex-0.2.0-windows-x64-setup.exe** — the Windows installer.
- **Foldex-0.2.0-windows-x64-portable.zip** — extract the whole ZIP and run
  Foldex.exe.

GitHub's **Source code (zip)** and **Source code (tar.gz)** downloads contain
the corresponding source, not the Windows application.

Requires Windows 10 x64 (1809+) and compatible DirectX 12 graphics. The Visual
C++ runtime is included. Builds are unsigned, so Windows may show an
unknown-publisher prompt.

Update an installed copy through **Options → Application Updates**, or exit
Foldex and run the new installer. Your saved settings and themes are preserved.
Portable copies retain their existing storage behavior.
