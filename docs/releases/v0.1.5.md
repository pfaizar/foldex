Foldex 0.1.5 renames items in place, adds a This PC page and a Sort menu, and rebuilds the website.

- Rename and create items inline, as File Explorer does: press F2, click a selected name again, or use New folder, New file and shell New templates. Enter saves, Esc cancels, Tab moves to the next item, and a changed file extension asks first. Explorer's naming rules apply, including reserved names and "name (2)" numbering; several selected items still open the batch rename dialog.
- A This PC page lists every drive as a card with its free space. Double-click or Enter opens a drive, middle-click opens a tab, going up from a drive root lands there, and the Places menu can hide the row.
- A Sort button on the toolbar sorts every view, not only Details. It lists the visible columns, keeps the hidden ones under More, and offers Ascending and Descending. Numeric and date columns start largest or newest first.
- Every dialog now shares one layout: actions on the right with a single primary button, status on the left, and the window dimmed behind. Tab order follows the visual order.
- Errors appear in plain language instead of OS codes. Developer Mode in Settings adds the raw detail on a second line and unlocks Performance Details (Ctrl+Alt+P) and an Error Log shortcut.
- The default color scheme is neutral; folders and destructive actions keep their color. Untouched schemes upgrade automatically, saved schemes are left alone, and the old palette returns through Load Themes from docs/themes/Classic.toml.
- Choose where folders open from the launcher: replace the current tab, open a new tab (the default) or open a new window.
- Calculator answers in the launcher appear as one compact row, with Enter to copy.
- Places shows the Windows user icon and an empty or full Recycle Bin, and the footer is now a bar whose view-size wedge widens with icon size.
- Dragging starts only from a selected item's icon or name; a drag anywhere else draws a selection rectangle, so large folders still select the Explorer way.
- Fixes: explorer controls no longer flicker while the launcher is open, go-to rows stay visible when a folder is listed again, and after an update Foldex restarts once without the inherited Redirection Guard policy that broke user-created junctions such as nvm, scoop and pnpm links.
- The website is rebuilt around the app's own interface, with a working launcher demo, benchmarks against File Explorer, Changelog and Documentation pages, and a download that matches each visitor's system.

- **Foldex-0.1.5-windows-x64-setup.exe** — the Windows installer.
- **Foldex-0.1.5-windows-x64-portable.zip** — extract the whole ZIP and run Foldex.exe.

GitHub's **Source code (zip)** and **Source code (tar.gz)** downloads contain the corresponding source, not the Windows application.

Requires Windows 10 x64 (1809+) and compatible DirectX 12 graphics. The Visual C++ runtime is included. Builds are unsigned, so Windows may show an unknown-publisher prompt.

Update an installed copy through **Options → Application Updates**, or exit Foldex and run the new installer. Your saved settings and themes are preserved. Portable copies retain their existing storage behavior.
