Foldex 0.1.4 brings faster, more complete search and large-folder browsing, a tidier search bar and fixes for shortcut recording.

- Search results stay live: folders being searched share one live catalog, large result lists page in smoothly, and a search folder that is deleted and recreated is picked up again automatically.
- Large folders can be loaded in full with **Load all items**, and file details such as dates and cloud availability fill in without blocking the list.
- Search conditions now open from a filter button inside the search bar, and combined searches can be saved as collections.
- Shell actions run independently of each other, operation history is kept per action, and list rows are exposed to screen readers.
- Shortcut recording keeps working after settings refresh. Previously the recorder could silently stop capturing keys.
- Launcher shortcuts that use the Windows key, such as Win+Space, are now registered through a keyboard hook. This is new; if a Windows-key shortcut does not respond on your machine, choose a different combination.
- Redundant helper text was removed from several dialogs.

GitHub's **Source code (zip)** and **Source code (tar.gz)** downloads contain the corresponding source, not the Windows application.

Requires Windows 10 x64 (1809+) and compatible DirectX 12 graphics. The Visual C++ runtime is included. Builds are unsigned, so Windows may show an unknown-publisher prompt.

Update an installed copy through **Options → Application Updates**, or exit Foldex and run the new installer. Your saved settings and themes are preserved. Portable copies retain their existing storage behavior.
