Foldex 0.1.2 fixes shortcut configuration and recording.

- Configure all keyboard shortcuts in **Hotkeys**, including the global Launcher shortcut. The duplicate Launcher Shortcut option has been removed from Options, and your existing launcher shortcut is preserved.
- Record full combinations such as **Win+Ctrl+Shift+Alt+A**, with every modifier included.
- Record command sequences of any length without enabling a two-key mode. Keep pressing combinations, then choose **Assign** when finished. The global launcher shortcut uses one combination with any supported modifiers.
- Keep shortcut labels, saved bindings and the global launcher registration consistent. If Windows rejects a replacement shortcut, the previous working binding is retained.

**Download**

- **Foldex-0.1.2-windows-x64-setup.exe** — the Windows installer.
- **Foldex-0.1.2-windows-x64-portable.zip** — extract the whole ZIP and run Foldex.exe.

GitHub's **Source code (zip)** and **Source code (tar.gz)** downloads contain the corresponding source, not the Windows application.

Requires Windows 10 x64 (1809+) and compatible DirectX 12 graphics. The Visual C++ runtime is included. Builds are unsigned, so Windows may show an unknown-publisher prompt.

Update an installed copy through **Options → Application Updates**, or exit Foldex and run the new installer. Your saved settings and themes are preserved. Portable copies retain their existing storage behavior.
